## 4. Технический долг (debt) — приоритет HIGH

| Проблема | Риск | Предлагаемое решение |
|----------|------|---------------------|
| Сгенерированные Vivado-файлы в истории Git (~850 МБ) | Клонирование занимает минуты | `git filter-repo` / BFG Repo-Cleaner |
| Отсутствие полноценных тестбенчей | Регрессии не отлавливаются | Добавить UVM/SV или VHDL self-checking TB |
| Дублирование AXI FSM в каждом IP | Трудоёмкость поддержки | Вынести в `AxiLiteSlave` entity |
| Жёсткая привязка к Vivado Block Design | Портирование невозможно | Сгенерировать RTL-обёртку из BD Tcl |
| Нет синтезируемых assertions | Баги на silicon обнаруживаются поздно | Добавить PSL/SVA assertions |

## 5. Метрики успеха

- **Покрытие тестбенчами**: ≥ 70% IP-ядер имеют smoke-test
- **Размер репозитория**: < 20 МБ после очистки истории
- **Время CI**: < 5 минут на структурные проверки
- **Платформы**: ≥ 2 вендора FPGA (Xilinx + 1)
- **Языки документации**: EN + RU
