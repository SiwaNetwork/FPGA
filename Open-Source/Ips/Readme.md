## Пользовательские интерфейсы
Файлы .xml в папке определяют пользовательские интерфейсы, которые используются IP-ядрами проекта. 
В настоящее время существует 3 пользовательских интерфейса.

| Имя интерфейса | Описание интерфейса |
|----------------|-----------------------|
| [Time](TC_Time_rtl.xml) | Содержит текущий счётчик времени в секундах и наносекундах, а также бит корректности и флаг, уведомляющий о жёсткой установке времени. |
| [ClockAdjustment](TC_ClockAdjustment_rtl.xml) | Содержит корректировку времени в секундах, наносекундах, направлении, интервале, на протяжении которого должна быть применена корректировка, и бит корректности |
| [Servo](TC_Servo_rtl.xml) | Содержит коэффициенты PI-сервопривода |

## IP-ядра
Каждое пользовательское открытое IP-ядро определено в отдельной папке. Каждая папка IP-ядра имеет похожую структуру 
- Файл **Readme.md**, который описывает ядро FPGA (обзор контекста, описание набора регистров, описание проекта и т.д.)     
- Файлы **.vhd** ядра
- Папка **Xilinx** содержит специфичные для производителя файлы IPI для интеграции ядер в инструмент Vivado
- Папка **Additional Files** содержит файлы (например, изображения) для документации ядра, а для некоторых ядер — шаблоны файлов
