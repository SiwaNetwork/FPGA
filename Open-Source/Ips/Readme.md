## Пользовательские интерфейсы
Файлы .xml в папке определяют пользовательские интерфейсы, используемые IP-ядрами проекта. 
В настоящее время существуют 3 пользовательских интерфейса.

| Название интерфейса | Описание интерфейса |
|----------------|-----------------------|
| [Time](TC_Time_rtl.xml) | Содержит текущий счетчик времени в секундах и наносекундах, а также бит валидности и флаг, уведомляющий о жесткой установке времени. |
| [ClockAdjustment](TC_ClockAdjustment_rtl.xml) | Содержит корректировку времени в секундах, наносекундах, направлении, интервале, на протяжении которого должна применяться корректировка, и валидности |
| [Servo](TC_Servo_rtl.xml) | Содержит коэффициенты PI-сервоконтура |

## IP-ядра
Каждое пользовательское IP-ядро с открытым исходным кодом определено в отдельной папке. Каждая папка IP-ядра имеет схожую структуру 
- Файл **Readme.md**, который описывает ядро FPGA (обзор контекста, описание набора регистров, описание проекта и т.д.)     
- Файлы **.vhd** ядра
- Папка **Xilinx** содержит специфичные для производителя файлы IPI для интеграции ядер в инструмент Vivado
- Папка **Additional Files** содержит файлы (например, изображения) для документации ядра и — для некоторых ядер — шаблоны файлов
