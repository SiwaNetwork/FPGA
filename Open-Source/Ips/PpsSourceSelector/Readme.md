## 1. Context Overview
PPS Source Selector — это полностью аппаратная (только FPGA) реализация, которая обнаруживает доступные источники PPS и выбирает источник PPS в соответствии со схемой приоритетов и конфигурацией.  
Конфигурация и контроль ядра осуществляются через опциональный внешний интерфейс ведомого AXI4L (см. набор регистров [Clock Detector](../ClockDetector)). 
Если вход конфигурации не предоставлен, то выбор PPS выполняется на основе доступных входов PPS и схемы приоритетов по умолчанию.  
## 2. Interface Description
### 2.1 PPS Source Selector IP
Интерфейс PPS Source Selector:
- System Reset и System Clock на вход
- Конфигурация для выбора источника PPS на вход (обычно предоставляется внешним интерфейсом ведомого AXI4L)
- Доступные источники PPS на выход (обычно предоставляются внешнему интерфейсу ведомого AXI4L)
- Сигналы PPS на вход (SMA, MAC, GPS)
- Выбранные сигналы PPS на выход (PPS Slave, MAC)

## 3 Design Description
PPS Source Selector обнаруживает и оценивает доступные входы PPS и выбирает те, которые будут использоваться, на основе входа конфигурации и схемы приоритетов. 
Компонент состоит из 2 основных операций:
- Оценка доступных входов PPS
- Выбор источников PPS
### 3.1 Evaluate the available clocks
Вход PPS считается доступным, если он проходит 2 критерия оценки:
- Период импульса считается корректным, если период импульса составляет 1 секунду с допуском ±10%
- Период импульса остаётся корректным более чем «Pps Available Threshold» секунд подряд 
### 3.2 Select the PPS sources
Существует 4 возможных варианта конфигурации для выбора источника Slave PPS.
|Configuration|Source Select Value|Description|
|-------------|:-----------------:|-----------|
|Автоматический выбор|0|Приоритет выбора по умолчанию: (1) SMA PPS (2) MAC PPS (3) GPS PPS|
|SMA|1|Принудительно подать вход SMA PPS на выход Slave PPS. Если SMA PPS недоступен, выход равен 0.|
|MAC|2|Принудительно подать вход MAC PPS на выход Slave PPS. Если MAC PPS недоступен, выход равен 0.|
|GPS|3|Принудительно подать вход GPS PPS на выход Slave PPS. Если GPS PPS недоступен, выход равен 0.|

Существует 3 возможных варианта конфигурации для выбора источника MAC PPS.
|Configuration|Source Select Value|Description|
|-------------|:-----------------:|-----------|
|Автоматический выбор|0|Приоритет выбора по умолчанию: (1) SMA PPS (2) GPS PPS 
|SMA|1|Принудительно подать вход SMA PPS на выход MAC PPS. Если SMA PPS недоступен, выход равен 0.|
|GPS|2/3|Принудительно подать вход GPS PPS на выход MAC PPS. Если GPS PPS недоступен, выход равен 0.|
