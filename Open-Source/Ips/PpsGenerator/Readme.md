## 1. Context Overview
PPS Generator — это полностью аппаратная (только FPGA) реализация, которая генерирует импульс Pulse Per Second (PPS), выровненный по началу новой секунды локальных часов. Ядро может быть сконфигурировано через интерфейс регистров AXI4Lite-Slave.
## 2. Interface Description
### 2.1 PPS Generator IP
Интерфейс PPS Generator:
- System Reset и System Clock на вход
- Вход высокоразрешающих часов, для высокоточных меток времени (целое кратное System Clock, с фиксированным соотношением к System Clock, например, от того же PLL)
- Вход локального времени, от [Adjustable Clock](../AdjustableClock/Readme.md)
- Интерфейс ведомого AXI4L, через который CPU читает и записывает регистры PPS
- Выходной сигнал PPS
 
![PPS Generator IP](Additional%20Files/PpsGenIp.png) 

Параметры конфигурации ядра:
- Период системного тактового сигнала в наносекундах.
- Множитель частоты высокого разрешения, показывающий, во сколько раз тактовый сигнал высокого разрешения быстрее системного  
- Опция включения/отключения компенсации задержки кабеля. Если включена, генератор компенсирует задержку кабеля, которая задаётся в наносекундах через конфигурацию AXI. 
- Задержка на выходе в наносекундах, которая будет компенсирована генератором. Может быть только положительным значением.
- Полярность генерируемого сигнала. Если '1', то сигнал активен по высокому уровню. Иначе — по низкому.

## 3. Register Set
Это набор регистров PPS Generator. Доступ осуществляется через AXI4 Light Memory Mapped. Все регистры 32-битные, не поддерживаются пакетный доступ, невыровненный доступ, byte enables, таймауты. Адресное пространство регистров не является непрерывным. Адреса регистров — это только смещения в области памяти, где ядро отображено в AXI inter connects. Обращение к несуществующему регистру в отображённой области памяти возвращает ошибку декодирования ведомого.

## 4 Design Description
PPS Generator принимает (синхронизированный) вход времени в качестве опорного и генерирует импульс Pulse Per Second, выровненный по этим часам (время старта и период), компенсируя выходную задержку. PPS Generator содержит ведомый AXI4Lite для конфигурации и контроля статуса со стороны CPU. Компонент состоит из 3 основных операций:
- Периодическая генерация импульса, выровненного по локальному времени
- Точная подстройка момента активации импульса с помощью тактового сигнала высокого разрешения   
- Интерфейс с CPU (AXI master) через ведомый AXI
### 4.1 Periodically generate the PPS
Когда генерация PPS включена, генерация начинается в начале новой секунды локального времени. Это делается путём сравнения текущего локального времени с максимальным значением наносекунд (1000000000) минус накопленные выходные задержки. Для генерации импульса с высоким разрешением подсчитывается, сколько периодов высокого разрешения «помещается» между этими двумя сравниваемыми значениями, и это сохраняется в сдвиговом регистре.  
Скважность импульса в настоящее время фиксирована на уровне 500 мс. Обратите внимание, что скважность считается свободно работающим счётчиком, поэтому деактивация импульса не выровнена по локальному времени. 
Если локальное время отключается или происходит скачок времени, генератор PPS сообщает об ошибке. Генерация импульса продолжится, если условие ошибки устранено и импульс деактивирован.  
### 4.2 Compute the exact time of the generation
Для вычисления точного момента генерации, помимо компенсации выходных задержек, импульс также в конечном итоге генерируется с помощью тактового сигнала высокого разрешения, частота которого является кратной частоте системного тактового сигнала. Сдвиговый регистр, отмеченный в домене системного тактового сигнала (см. [Главу 4.1](#4-1-periodically-generate-the-pps)), передаётся в домен тактового сигнала высокого разрешения. Количество периодов высокого разрешения, которые «помещаются» в эту разницу во времени, указывает, когда тактовый сигнал высокого разрешения должен генерировать PPS.    
### 4.3 AXI slave of the PPS Generator 
PPS Generator включает ведомый AXI Light Memory Mapped. Он обеспечивает доступ ко всем регистрам и позволяет конфигурировать PPS Generator. AXI Master должен конфигурировать наборы данных записью в регистры через AXI, что обычно выполняется CPU. Также предоставляется интерфейс статуса, позволяющий контролировать состояние генератора. Полное описание набора регистров приведено в [Главе 3](#3-register-set).
