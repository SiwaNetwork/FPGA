## 1. Обзор контекста
Signal Timestamper — это полностью аппаратная (только FPGA) реализация. Он позволяет делать метки времени событийного сигнала с настраиваемой полярностью. Метки времени делаются по сконфигурированному фронту сигнала и генерируются прерывания. Signal Timestamper предназначен для подключения к CPU или любому другому AXI master, который может считывать метки времени. Настройки конфигурируются через интерфейс регистров AXI4Lite-Slave.  

## 2. Описание интерфейса
### 2.1 IP Signal Timestamper
Интерфейс Signal Timestamper:
- System Reset и System Clock на вход
- Вход высокочастотного тактового сигнала для высокоточных меток времени (целое кратное частоты System Clock с фиксированным соотношением к системному такту, например, от того же PLL)
- Вход локального времени от [Adjustable Clock](../AdjustableClock/Readme.md)
- Вход события, для которого будет сделана метка времени- Интерфейс slave AXI4L, через который CPU читает и записывает регистры таймстампера
- Опциональный выход прерывания, когда сделана метка времени
 
![Signal Timestamper IP](Additional%20Files/SigTimestamper%20IP.png) 

Параметры конфигурации ядра:
- Период системного тактового сигнала в наносекундах.
- Множитель частоты высокого разрешения, показывающий, во сколько раз быстрее тактовый сигнал высокого разрешения по сравнению с системным  
- Опция включения/отключения поддержки задержки кабеля. Если включено, таймстампер компенсирует задержку кабеля, которая задаётся в наносекундах через конфигурацию AXI. 
- Задержка входа в наносекундах, которая будет компенсирована таймстампером (например, для буферов, всегда положительная)
- Полярность входного события. Если '1', метка времени делается по фронту нарастания события. Иначе — по фронту спада события.

## 3. Набор регистров
Это набор регистров Signal Timestamper. Доступ осуществляется через AXI4 Light Memory Mapped. Все регистры 32-битные, не поддерживаются пакетный доступ, невыровненный доступ, byte enables, таймауты. Адресное пространство регистров не непрерывно. Адреса регистров — это только смещения в области памяти, где ядро отображено в AXI interconnect. Обращение к несуществующему регистру в отображённой области памяти возвращает ошибку декодирования slave.

## 4 Описание проекта
Signal Timestamper принимает (синхронизированное) входное время в качестве опорного, событийный сигнал и генерирует метки времени опорных часов по настраиваемому фронту (полярности) событийного сигнала, компенсируя задержку входа. Событие метки времени также вызывает прерывание, чтобы сообщить CPU о том, что событие произошло и метка времени готова к считыванию. При обнаружении каждого фронта увеличивается внутренний счётчик, что позволяет обнаружить пропущенные события, поскольку таймстампер отключает себя до тех пор, пока CPU не сбросит прерывание. Он содержит slave AXI4Lite для конфигурации, контроля статуса и считывания меток времени со стороны CPU. Компонент разделён на 3 основные операции:
- Снятие метки времени входного события с тактовым сигналом высокого разрешения
- Вычисление точного времени метки
- Интерфейс с CPU (AXI master) через AXI slave
### 4.1 Метка времени с тактовым сигналом высокого разрешения
Частота тактового сигнала высокого разрешения является целым кратным частоты системного тактового сигнала (задаётся в конфигурации). Тактовый сигнал высокого разрешения используется для уменьшения джиттера метки времени. При получении события тактовый сигнал высокого разрешения отмечает событие в сдвиговом регистре. Сдвиговый регистр копируется в домен системного тактового сигнала, и таким образом "окно" высокого разрешения может быть идентифицировано и соответствующим образом компенсировано.      
### 4.2 Вычисление точного времени метки
Для вычисления точного времени метки компенсируются следующие задержки:
- **задержка высокого разрешения**. Как описано в [Главе 4.1](#4-1-timestamp-with-the-high-resolution-clock), метка времени с тактовым сигналом высокого разрешения уменьшает джиттер метки времени за счёт вычисления задержки высокого разрешения. Эта задержка включает смещение регистра при переключении между доменами тактовых сигналов и разницу между фронтом нарастания системного тактового сигнала и тактового сигнала высокого разрешения в момент события.  
- **задержка входа**. Она задаётся как параметр конфигурации ядра во время компиляции. Может быть только положительным значением.
- **задержка кабеля**. Она задаётся как параметр конфигурации через регистр AXI при условии, что компенсация задержки кабеля включена. Может быть только положительным значением.
### 4.3 AXI slave Signal Timestamper 
Signal Timestamper включает AXI Light Memory Mapped Slave. Он предоставляет доступ ко всем регистрам и позволяет конфигурировать Signal Timestamper. AXI Master должен конфигурировать наборы данных записью AXI в регистры, что обычно выполняется CPU. Он также предоставляет интерфейс статуса, позволяющий контролировать состояние таймстампера. Полное описание набора регистров приведено в [Главе 3](#3-register-set).
