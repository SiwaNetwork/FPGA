## 1. Общий обзор контекста
Frequency Counter — это полностью аппаратная (FPGA) реализация, которая измеряет частоту входного сигнала.
Счетчик вычисляет не дробные частоты в диапазоне [0 Гц - 10'000'000 Гц] и синхронизируется с новой секундой локальных часов.
Ядро может конфигурироваться через интерфейс регистров AXI4Lite-Slave.
## 2. Описание интерфейса
### 2.1 Frequency Counter IP
Интерфейс Frequency Counter:
- System Reset и System Clock на входе
- Входной сигнал, частоту которого необходимо измерить
- Вход локального времени от [Adjustable Clock](../AdjustableClock/Readme.md)
- AXI4L slave интерфейс, через который CPU считывает и записывает регистры ядра

## 3. Набор регистров
Это набор регистров Frequency Counter. Доступ осуществляется через AXI4 Light Memory Mapped.
Все регистры имеют ширину 32 бита, не поддерживается пакетный доступ, невыровненный доступ, byte enables, таймауты.
Пространство адресов регистров не является непрерывным.
Адреса регистров являются только смещениями в области памяти, где ядро отображается в AXI interconnect.
Обращение к несуществующему регистру в отображенной области памяти возвращает ошибку декодирования slave.

## 4 Описание архитектуры
Frequency Counter получает (синхронизированный) вход времени и вход сигнала/частоты и измеряет частоту сигнала за заданное количество секунд.
Ядро содержит AXI4Lite slave для конфигурации и контроля состояния со стороны CPU.
Компонент состоит из 2 основных операций:
- Измерение частоты входного сигнала
- Интерфейс с CPU (AXI master) через AXI slave
### 4.1 Измерение частоты входного сигнала
Ядро начинает измерение частоты сигнала после предоставления его конфигурации.
Конфигурация включает (i) флаг разрешения и (ii) период измерения.
Период измерения — это количество секунд, в течение которых будет измеряться частота, и его диапазон составляет 1-255.
Период измерения со значением ноль считается неверной конфигурацией.
После включения ядра, в начале следующей секунды (входного времени), частотный счетчик начинает считать нарастающие фронты входного сигнала в течение сконфигурированного периода измерения.
После истечения периода измерения подсчитанное значение делится на этот период измерения, и целочисленный результат записывается в выделенный регистр.
Затем начинается новое измерение.
Если вычисленный результат превышает 10 МГц, то устанавливается флаг ошибки.
### 4.2 AXI slave Frequency Counter
Frequency Counter включает AXI Light Memory Mapped Slave. Он предоставляет доступ ко всем регистрам и позволяет конфигурировать ядро.
AXI Master должен конфигурировать наборы данных записью в регистры через AXI, что обычно выполняется CPU.
Он также предоставляет регистр частоты, который позволяет контролировать состояние частотного счета. [Глава 3](#3-register-set) содержит полное описание набора регистров.
